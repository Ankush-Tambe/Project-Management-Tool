Application Type: Full-stack project management web application built with a modern JavaScript stack.
Frontend: Powered by React and Vite to deliver an interactive user interface featuring dashboards, user authentication pages for login and registration, and detailed project views.
Backend: Structured around Node.js and Express, organizing core logic into separate controllers and routes for handling user authentication, projects, and tasks.
Database & Data Management: Uses MongoDB models to manage data entities including users, tasks, projects, and comments, ensuring a scalable structure for tracking work items and team collaboration.
